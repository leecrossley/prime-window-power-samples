# Contributing to this result

Ongoing work on this result belongs in [`leecrossley/prime-window-rh-criterion`](https://github.com/leecrossley/prime-window-rh-criterion/tree/main/results/prime-window-power-samples). Edit its `results/prime-window-power-samples/` directory in a branch of that repository and open the pull request there. For a distinct note on the same mathematical question, add a result directory and an entry in the [family index](https://github.com/leecrossley/prime-window-rh-criterion/blob/main/RESULTS.md).

Use the [research contribution guide](https://github.com/leecrossley/prime-window-rh-criterion/blob/main/AGENTS.md) to choose a different family when the mathematical scope calls for it. Keep the [original releases](https://github.com/leecrossley/prime-window-power-samples/releases), citation identifiers and verification records available.
